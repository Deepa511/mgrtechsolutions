# MGRTECH Solutions — Marketing Site

Marketing site for MGRTECH SOLUTIONS, Inc. (Ashland, MA), a web development
and AI automation studio serving MetroWest Massachusetts. Built with
Next.js App Router, TypeScript, Tailwind v4, Framer Motion, and Lenis;
deployed on Vercel.
